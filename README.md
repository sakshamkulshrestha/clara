# discord bot

typescript, discord.js v14, nvidia nim for ai.

## setup

1. create an app at discord.com/developers, add a bot, copy the token
2. in the bot tab enable **message content intent**
3. copy `.env.example` to `.env` and fill in `DISCORD_TOKEN` and `NVIDIA_API_KEY` (get one at build.nvidia.com)
4. `npm install`
5. `npm run dev`

invite with the `bot` scope and these permissions: administrator is easiest, or manage roles / channels / messages / nicknames, kick, ban, moderate members, send messages, embed links.
the bot's role must sit above any role it needs to manage.

## structure

```
src/
  index.ts             client, command handler, ai triggers
  config.ts            env
  lib/ai.ts            nvidia client, persona, memory, action lines
  lib/db.ts            tiny json store (data.json)
  lib/util.ts          parsing + reply helpers
  commands/
    moderation.ts      ban unban kick timeout untimeout warn warnings clearwarns purge lock unlock slowmode addrole removerole nick
    utilities.ts       avatar banner serverbanner servericon userinfo channelinfo roleinfo serverinfo membercount roles ping
    ai.ts              aichannel ask forget roast
    index.ts           registry + help
```

## notes

- prefix is `.` by default (change `PREFIX` in `.env`). aliases: `av`, `ui`, `ci`, `ri`, `si`, `sb`, `ub`, `mc`
- ping the bot to chat. it remembers your last turns and sees the server, channel and recent messages
- `.aichannel` toggles a channel where the bot answers every message
- moderation replies are generated by the model so they are never the same twice. without an api key they fall back to short fixed lines
- change the personality in `persona` inside `src/lib/ai.ts`
- change the model with `NVIDIA_MODEL` (any chat model from build.nvidia.com)
- adding a command: add an object to the array in the matching file in `src/commands`
